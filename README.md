# SIGEAT

**Special Interest Group on Eating & Tasting**

> From Information Retrieval to Food Retrieval.

**Eat. Review. Rank. Repeat.**

SIGEAT is a recurring dining series based in Brisbane, Australia.

Inspired by the organisational language of academic special interest groups,
SIGEAT provides a lightweight framework for recording, reviewing, and comparing
shared dining experiences.

A restaurant becomes a **Venue**, a dinner becomes a **Session**, each ordered
dish becomes a **Paper**, tasting becomes **Peer Review**, and the resulting
record becomes the **Proceedings**.

## Website

This repository contains the static website for SIGEAT.

The site includes:

- upcoming SIGEAT sessions
- session proceedings
- reviewed dishes and Best Paper awards
- venue records and rankings
- future-session bidding
- information about the SIGEAT format

## SIGEAT Vocabulary

|SIGEAT term	|Meaning|
| -------- | -------- |
|Session	|One dinner|
|Venue	|Restaurant|
|Paper	|Ordered dish|
|Peer Review	|Shared tasting and evaluation|
|Review	|Individual assessment|
|Decision	|Final evaluation|
|Best Paper	|Favourite dish|
|Proceedings	|Archived session record|

Academic terminology is used only where it maps meaningfully to an actual
part of the dining experience.
